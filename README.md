# OTL Specifications

This repository holds the protocol specifications of the Open Transaction Layer (OTL).

- [`identity/identity-spec.md`](identity/identity-spec.md) is the normative identity specification.
- [`identity/threat-analysis.md`](identity/threat-analysis.md) is a non-normative threat analysis that accompanies the identity specification.
